# A Light Weight **Password manager** I built this to store my card numbers and login Credentials Securely

## Features
 -**Credentials Storage** - Save Website Name, Username, and Password & Card Details also

## Tech Stack
 -**Frontend** & **Backend** - TypeScript
 -**Storage** - Clerk Private MetaData
 -**Authentication** - Clerk

## What I Learnt
 -**Auth with Clerk** - I learnt how to authenticate ser with Clerk
 -**Saving credentials in Clerk** - I learnt how to save data in Clerk Private MetaData 

## Most Challenging Part
 The Most Challenging part was when I am trying to auth with clerk but it repeatedely shows the error. But, with concentration and clerk doocumentation i found the error and sorted it.
